# two-layer-polling-monitor

定期監視を「スクリプト時計（第1層）＋エージェント（第2層）」の2層に分けて、トークンコストを抑えるための設計スキルです。

エージェント cron で数分おきにポーリングすると、処理自体が軽くても起動時の固定費（設定・記憶・指示文の読み込み）が毎回かかり、1分間隔では1日あたり数千万トークン規模になります。このスキルは、機械的に判定できる監視をスクリプトに寄せ、エージェントはイベントのときだけ起こす形に設計し直す手順と、コストの目安、検証と導入の進め方（シミュレーション検算→影モード→live 切替）を提供します。

## 使い方

このフォルダを、使用するエージェント環境のスキル置き場へコピーしてください。本体は `SKILL.md` です。

- `SKILL.md` — 使い分け・コスト表・設計ルール・導入手順・落とし穴
- `templates/hook-wrapper.sh` — hook ラッパーの雛形
- `templates/state-schema.json` — 状態ファイルの骨格
- `examples/character-letters.md` — キャラクターの自発行動システムへの適用実例
